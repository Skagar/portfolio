# Samaksha Agarwal — Software Engineering Portfolio

A refined, high-performance personal developer portfolio engineered for **Samaksha Agarwal**, Computer Science undergraduate at Jaypee Institute of Information Technology (JIIT Noida) specializing in **Java Backend Development, Distributed Systems, and Relational Database Architectures**.

Built with React 18, Vite, Tailwind CSS, and Framer Motion, inspired by clean minimal European typography and modern engineering portfolio aesthetics.

---

## ⚡ Key Highlights

- **Aesthetic Direction:** Minimalist deep black (`#090909`), subtle charcoal cards (`#141416`), clean neutral typography, and tasteful crimson red (`#D92332`) accents.
- **Verified Telemetry & Milestones:** Animated counters showcasing 500+ DSA problems solved, 8.82/10 CGPA, 10-microservice architecture, and 10,000+ Kafka messages processed per run.
- **Richer Technical Proficiencies:** Structured into 6 balanced categories with technology-specific Lucide icons, subtle crimson focus badges for Java, Spring Boot, PostgreSQL, Kafka, Docker, and DSA.
- **Interactive System Architecture Spec:** Deep-dive modal inspecting RainIQ's 10-service decomposition, Kafka event streams, and BookMyShow's transactional booking workflows and relational entity modeling.
- **Direct Recruiter Contact Panel:** Form-free, high-efficiency contact grid with one-click clipboard copy for Email & Phone, functional `tel:` link, and direct links to GitHub, LinkedIn, and LeetCode.
- **Dual Resume Support:** In-app **"View Resume"** PDF modal preview alongside direct **"Download Resume"** functionality.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation & Development
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
